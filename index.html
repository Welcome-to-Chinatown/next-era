TRY IT Practice: the reorder dashboard ›

Turn a messy café inventory into a one-page reorder dashboard and ready-to-send supplier emails. Works in any AI chat tool that can read a file (ChatGPT, Claude, Gemini).

  1. Download the data: procurement_inventory.csv — a sample café stock list (on hand, par level, unit cost, supplier).
  2. Start a new chat, attach that file, then paste this prompt:
Role and goal. You are my operations assistant for a small café. I am giving you my inventory as a CSV. I want two things from it: a clear reorder dashboard I can look at, and reorder emails I can send today.

Steps.
1. Read the CSV. Flag every item where on_hand is below par_level.
2. For each flagged item, calculate units to order to reach par (par_level minus on_hand) and the reorder cost (units to order times unit_cost).
3. Group the flagged items by supplier.
4. Build the dashboard, then write the emails.

Output.
- First, a single-page dashboard as an artifact. Include: total items tracked, number of items below par, total reorder cost across all suppliers, a bar chart of reorder cost by supplier, and a table of every below-par item with its supplier, on hand, par, units to order, and cost. Make it clean and easy to read.
- Then, one reorder email per supplier, addressed to that supplier's email from the file. Each email lists the items to reorder and the quantity to bring each back to par, in a warm and professional tone, and asks for delivery within that supplier's lead time.

Eval. Before you finish, check three things: every below-par item shows up once under the correct supplier in both the dashboard and an email; units to order equals par minus on hand for each item; and the reorder cost totals match between the table and the chart.

You should get: a dashboard with about 15 items below par across 6 suppliers, plus one reorder email per supplier.

TRY IT Practice: the finance dashboard ›

A home-goods shop has 100 orders in a messy spreadsheet (mixed date styles, mismatched category names, refunds). Ask AI to clean it and build a dashboard of what is selling, what is returned, and when.

  1. Download the data: retail_store_data.csv — 100 sample orders, messy on purpose (not a real business).
  2. Start a new chat, attach that file, then paste this prompt (fill in the [brackets]):
Role & goal: You are my business analyst. I run [type of shop] and I want a dashboard that shows how my shop is doing.
Steps:
1. Clean the data: read all the date styles, merge category names that mean the same thing, trim extra spaces.
2. Calculate total revenue (use the Total column), number of orders, average order value, and total refunds. Do not subtract refunds from revenue.
3. Show sales by category and sales by month.
4. List the top 10 items by revenue.
Output: A simple dashboard with four number cards, a bar chart, a line chart, and a table. Plain English labels, no jargon.
Eval: Before you answer, check your totals against the file and tell me which cleaning choices you made.

Check your numbers: revenue about $3,825, 100 orders, average order about $38, refunds $321.52, 6 categories after merging. Full walkthrough in the handout above.

VIBE CODE Vibe-coded exercise: the restaurant reorder dashboard ›

A restaurant has 32 items in a messy inventory file. Instead of asking a chat for one answer, you have a coding agent build a reorder dashboard from a plain-language instructions file: what is running low, what to order, and what it costs.

  1. Download the two files: CLAUDE.md (the instructions) and restaurant_inventory.csv (the data). Sample data, not a real business.
  2. Make a new folder and put both files in it. Save the instructions file as CLAUDE.md for Claude Code, AGENTS.md for Codex, or GEMINI.md for Gemini CLI.
  3. Open your coding agent in that folder, then paste this prompt:
Build the dashboard described in my [CLAUDE.md / AGENTS.md / GEMINI.md] file. This folder already has my md file and the inventory CSV, so do not overwrite them. Ask me any questions before you start. When it is ready, run it locally so I can open it at localhost:3000.

Check your numbers: 32 items tracked, 22 below par, reorder cost about $1,981, 1 out of stock. Then ask for one change, like "show only urgent items." Use sample data only.
