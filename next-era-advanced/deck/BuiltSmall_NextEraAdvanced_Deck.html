Find the draining task

Start with a PITA

Start with a PITA.

Pain In The Ass. The task you do again and again that quietly eats your week.

Not the big one-time project. The small repeat one.

Sounds like
  • Re-typing the same intake form
  • Drafting the same client email
  • Sorting the same expenses every month
  • Writing another version of the same post
The rule

Do it once, skip it. Do it every week, audit it.

Repetition is the signal. If the task keeps coming back, it is worth a look.

Is it AI-shaped?

The three filters

1
Repetitive
You do it the same way, again and again.
Yes the weekly reportNo a one-time decision
2
Text or data
It is writing, sorting, or summarizing information.
Yes emails, lists, forms, numbersNo a handshake or a phone call
3
Describable
You can write the steps down for someone brand new.
Yes you can explain howNo it is pure gut feel
Three yes answers means you have found an AI-shaped problem.
Name it in one line

The problem statement

My pain point is that [the task].
If I had [a better way],
I would [the impact].
Start with the problem. The greyed-out half, the solution, comes after you run the filters.

Your turn · 5 minutes

Write your PITA

  • Pick one task you do every week.
  • Mark the step that is slowest or most repetitive.
  • Fill in: My pain point is that ___. If I had ___, I would ___.
  • Turn to a neighbor and read it out loud.
Keep it. We will use it again at the end.

Two words, defined

Prompt vs prompt engineering

Prompt
What you type into the AI. Your request, in plain words.
Prompt engineering
Shaping that request so the answer comes back useful. Same model, better ask, better result.
You already do this. Today we make it deliberate.
The through-line

One framework, three moves

PartWhat to doExample
Role & GoalTell AI who it is and what to accomplishYou are my bookkeeper. Sort last month's expenses.
StepsBreak the task into clear numbered steps1. Group by category. 2. Total each. 3. Flag anything odd.
OutputSay exactly what you want backA table I can paste into a spreadsheet.
EvalAsk AI to check its own workConfirm every expense is counted once.
Zero-shot is your starting ask. Role play, chain of thought, and a clear output are what you add when the plain ask is not enough. Same framework, sharper each time.
The reveal

Watch the ask change the answer

Low level prompt
"Write a caption for an ice cream shop."
Generic. It could belong to any shop, anywhere.
High level prompt
Role & goal: You are Soft Swerve's social manager. Write an Instagram caption for the new ube coconut swirl.
Steps: name the flavor, make it playful, end with a call to visit.
Output: under 30 words, in English and Chinese.
Eval: check it sounds like a small shop, not a big brand.
Specific. You could post it today.
Same request. The shaping is the work.

Vibe coding

What is vibe coding?

You describe what you want in plain language, and the AI writes the code.
You say what you want, run it, look at it, and ask for changes. The term was coined by Andrej Karpathy in 2025.
Great for a first version. You stay the editor: you decide what “right” looks like.

The Context File (the .md)

Write it first
🧠
Your Project's Brain

A plain-language file the tool reads before every step, so it always knows your goal, your rules, and your plan. Each tool names it its own way: CLAUDE.md for Claude Code, AGENTS.md for Codex, or your tool's version. You don't hand-write it — the AI drafts it from your prompt, then you edit.

WHAT
Tool & structure
  • What it's built with
  • How files are organized
  • Key pieces
WHY
Purpose & function
  • What each part does
  • Who uses it
  • The real-world goal
HOW
Standards & rules
  • Your rules
  • How to test
  • What it must never do

The prompt that starts it

What we ask the coding agentBuild the dashboard described in my CLAUDE.md file. This folder already has my md file and the inventory CSV, so do not overwrite them. Ask me any questions before you start. When it is ready, run it locally so I can open it at localhost:3000.

Automation

Put your prompt on a schedule

Same prompt. Every week. Without you.
In Claude Cowork, a scheduled task saves your prompt and runs it at the time you pick.
  • Every Monday, summarize last week's sales in plain English.
  • Flag any category over 30% of income.
How you set it up1. Click Scheduled in the left sidebar 2. Click New task, then Create with Claude 3. Answer its questions 4. Review the name and schedule 5. Click Schedule
Automation

Good to know

How often
Hourly to weekly
Hourly, daily, weekly, on weekdays, or run it yourself whenever you want.
Where it runs
Cloud, mostly
Tasks run even when your computer sleeps. A task that needs your local files runs on your computer, so the app must be open.
Who has it
Paid plans
Scheduled tasks are on Pro, Max, Team and Enterprise. Team and Enterprise admins control access.
Start with the prompt card you wrote today. If it works by hand every time, it is ready to schedule. Check results before you rely on them.
Automation

Using ChatGPT or Gemini?

Claude Cowork
Scheduled > New task
Click Scheduled, then New task, then Create with Claude. Can work on files in a folder you connect.
ChatGPT
Describe it in a chat
Tell ChatGPT what to do and when. It saves it as a task. Free plans: up to 3 active tasks, once a day at most. Paid plans: up to hourly.
Gemini
Type it in the box
Write the prompt with when and how often, then Submit. Manage it on the Scheduled page. Daily, weekly or monthly. Up to 10 active. Needs Keep Activity on.
Menus and limits change. Try it once yourself before you rely on it. Not sure it can read your file? Use a prompt that needs no file.
